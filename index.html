Outpost Privacy Policy

Effective 13 November 2026

Outpost is a private publishing tool. Its owner runs it on the owner's own computer to publish posts to Facebook Pages that the owner manages. Outpost is not offered to the public and has no other users.

Information Outpost accesses

Outpost connects to Meta's Graph API with the permissions pages_show_list, pages_read_engagement and pages_manage_posts. Through them it accesses:

  • the list of Facebook Pages the owner manages: each Page's ID, name and the tasks the owner may perform on it;
  • access tokens for those Pages, used only to publish;
  • the IDs and links of posts that Outpost itself publishes, and the Pages' own recent posts when it needs to confirm that a post was published;
  • the name and ID of the Facebook account that authorised the app, to confirm that the login worked.

Information Outpost does not collect

Outpost does not collect, store or process information about followers, visitors, people who comment on or react to posts, or people who message the Pages. It uses no cookies, no analytics and no advertising.

How the information is used

Only to publish the owner's posts to the owner's Pages at the time the owner chooses, and to show the owner whether each post succeeded.

Where the information is kept

On the owner's own computer. The account access token is stored encrypted with Windows data protection (DPAPI). Page access tokens are held in memory only while the program runs. The text and files of posts the owner schedules are stored on the same computer. Outpost has no server on the internet, and it sends nothing anywhere except to Meta's Graph API.

Sharing

The information is not sold, rented or shared with anyone.

Keeping and deleting data

Data stays on the owner's computer until the owner deletes it. Deleting Outpost's secrets, data and logs folders removes everything Outpost has stored. Outpost's access can be withdrawn at any time in Facebook under Settings, Business integrations, by removing "Outpost".

Because Outpost keeps no data about other people, there is normally nothing to delete on request. Anyone who believes Outpost holds information about them can write to the contact address below. The request will be answered within 30 days.

Changes

If this policy changes, the new version will be published on this page with a new effective date.

Contact

นโยบายความเป็นส่วนตัวของ Outpost

มีผลตั้งแต่ 13 พฤศจิกายน 2026

Outpost เป็นเครื่องมือเผยแพร่โพสต์สำหรับใช้ส่วนตัว เจ้าของรันโปรแกรมบนคอมพิวเตอร์ของตัวเองเพื่อโพสต์ลงเพจ Facebook ที่เจ้าของดูแล Outpost ไม่ได้เปิดให้บุคคลทั่วไปใช้ และไม่มีผู้ใช้รายอื่น

ข้อมูลที่ Outpost เข้าถึง

Outpost เชื่อมต่อกับ Graph API ของ Meta ด้วยสิทธิ์ pages_show_list, pages_read_engagement และ pages_manage_posts โดยเข้าถึงข้อมูลต่อไปนี้

  • รายชื่อเพจ Facebook ที่เจ้าของดูแล ได้แก่ ID ของเพจ ชื่อเพจ และงานที่เจ้าของทำได้บนเพจนั้น
  • access token ของเพจเหล่านั้น ซึ่งใช้เพื่อเผยแพร่โพสต์เท่านั้น
  • ID และลิงก์ของโพสต์ที่ Outpost เผยแพร่เอง และโพสต์ล่าสุดของเพจเมื่อต้องยืนยันว่าโพสต์ขึ้นแล้ว
  • ชื่อและ ID ของบัญชี Facebook ที่อนุญาตแอป เพื่อยืนยันว่าการเข้าสู่ระบบสำเร็จ

ข้อมูลที่ Outpost ไม่เก็บ

Outpost ไม่เก็บ ไม่บันทึก และไม่ประมวลผลข้อมูลของผู้ติดตาม ผู้เข้าชม ผู้ที่แสดงความคิดเห็นหรือกดความรู้สึกต่อโพสต์ หรือผู้ที่ส่งข้อความถึงเพจ ไม่ใช้คุกกี้ ไม่ใช้ระบบวิเคราะห์ และไม่ใช้โฆษณา

การใช้ข้อมูล

ใช้เพื่อเผยแพร่โพสต์ของเจ้าของลงเพจของเจ้าของตามเวลาที่เจ้าของกำหนด และแสดงให้เจ้าของเห็นว่าโพสต์แต่ละรายการสำเร็จหรือไม่ เท่านั้น

ที่เก็บข้อมูล

ข้อมูลอยู่บนคอมพิวเตอร์ของเจ้าของ access token ของบัญชีถูกเก็บแบบเข้ารหัสด้วยระบบป้องกันข้อมูลของ Windows (DPAPI) access token ของเพจอยู่ในหน่วยความจำเฉพาะขณะโปรแกรมทำงาน ข้อความและไฟล์ของโพสต์ที่เจ้าของตั้งเวลาไว้เก็บอยู่บนคอมพิวเตอร์เครื่องเดียวกัน Outpost ไม่มีเซิร์ฟเวอร์บนอินเทอร์เน็ต และไม่ส่งข้อมูลไปที่ใดนอกจาก Graph API ของ Meta

การเปิดเผยข้อมูล

ไม่มีการขาย ให้เช่า หรือเปิดเผยข้อมูลแก่ผู้ใด

การเก็บรักษาและการลบข้อมูล

ข้อมูลอยู่บนคอมพิวเตอร์ของเจ้าของจนกว่าเจ้าของจะลบ การลบโฟลเดอร์ secrets, data และ logs ของ Outpost เป็นการลบทุกอย่างที่ Outpost เก็บไว้ และยกเลิกสิทธิ์ของ Outpost ได้ทุกเมื่อใน Facebook ที่เมนูการตั้งค่า การผสานการทำงานทางธุรกิจ โดยลบ "Outpost" ออก

เนื่องจาก Outpost ไม่เก็บข้อมูลของบุคคลอื่น โดยปกติจึงไม่มีข้อมูลให้ลบตามคำขอ ผู้ที่เชื่อว่า Outpost มีข้อมูลของตนสามารถติดต่อตามที่อยู่ด้านล่าง คำขอจะได้รับคำตอบภายใน 30 วัน

การเปลี่ยนแปลง

หากนโยบายนี้เปลี่ยนแปลง ฉบับใหม่จะเผยแพร่ในหน้านี้พร้อมวันที่มีผลใหม่
